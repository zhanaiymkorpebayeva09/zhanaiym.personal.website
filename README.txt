ZHANAIYM KORPEBAYEVA — WEBSITE PACKAGE

Contents
- index.html: complete, editable website with embedded photos, generated artwork,
  fonts, CSS and JavaScript. Font licensing notices are included in the HTML.
- README.txt: these instructions.

Publish
1. Extract this ZIP.
2. Upload index.html to your static host's public/root directory, or commit it
   at the root of your website repository and configure that directory for hosting.
3. No build command, package installation, API keys or backend are needed.
   If asked for a publish directory, select the directory containing index.html.

Preview
Open index.html in a modern browser. The diary expanders, mobile navigation,
quote controls, photos and fonts work without additional local files or internet.
External LinkedIn, Instagram and interview destinations require internet access.

Editing
Edit index.html in a text editor. Keep the embedded data URLs intact to preserve
images and fonts. Re-upload the file after editing.

Functionality
The diary entries are expandable text, not a database or editing application.
Opening an entry is a temporary viewing state; it resets when the page reloads.

Validation
HTML structure, navigation targets, embedded assets and JavaScript syntax were
checked. Diary, menu and quote event handlers were exercised in a simulated DOM.
A full visual browser test was not available in the creation environment.
